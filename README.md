# IPL Data Analytics using Python, Pandas & Power BI

## Project Overview
This project analyzes the Indian Premier League (IPL) dataset using Python, Pandas, and Power BI. The project includes data cleaning, exploratory data analysis (EDA), feature engineering, and an interactive Power BI dashboard to generate meaningful insights from IPL match data.

---

## Objectives
- Clean and preprocess IPL datasets.
- Perform Exploratory Data Analysis (EDA)
- Analyze team and player performance.
- Build an interactive Power BI dashboard
- Generate business insights from IPL data



##  Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Power BI
- Microsoft Excel



# Dataset
- matches.csv
- deliveries.csv

---

## Project Workflow

### Step 1: Data Collection
- Imported IPL datasets into Google Colab.

### Step 2: Data Cleaning
- Removed duplicate records
- Handled missing values.
- Corrected data types
- Cleaned inconsistent values.

### Step 3: Exploratory Data Analysis (EDA)
- Total Matches Played
- Matches Won by Team
- Toss Decision Analysis
- Venue Analysis
- Player of the Match Analysis
- Top Run Scorers
- Top Wicket Takers
- Boundary Analysis
- Season-wise Performance.

### Step 4: Data Visualization
Created charts using Matplotlib:
- Bar Charts
- Pie Charts
- Line Charts.
- Histograms

### Step 5: Power BI Dashboard
Created an interactive dashboard with:
- Total Matches
- Total Teams
- Total Seasons
- Team-wise Wins
- Venue Analysis
- Toss Winner Analysis
- Season Filter
- Team Filter
- Player Performance



## Key Insights
- Identified the most successful IPL teams.
- Analyzed player performance
- Compared venue-wise match results
- Found trends in toss decisions.
- Evaluated season-wise statistics.
